# Monsoon Desk

Monsoon Desk is a weather dashboard for Indian cities and locations worldwide. It uses the free [Open-Meteo API](https://open-meteo.com/) for geocoding and forecast data.

## Development

Requires Node.js and npm.

```sh
npm install
npm run dev
```

## Scripts

- `npm run dev` starts the development server.
- `npm run build` creates a production build.
- `npm run preview` serves the production build locally.
- `npm run lint` checks the TypeScript and React source.
